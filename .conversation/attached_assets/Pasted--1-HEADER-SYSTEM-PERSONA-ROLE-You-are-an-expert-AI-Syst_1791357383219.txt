# 2. CORE MISSION DIRECTIVE

Build **EcoCycle AI**, an AI-powered e-waste diagnostic, valuation, data-sanitization, and smart recycling matchmaker platform.

The platform solves three major problems in the e-waste lifecycle:

1. Users do not know whether an old electronic device should be resold, repaired, traded in, or recycled.
2. Users are afraid that personal data may remain on devices before selling or recycling them.
3. Users struggle to identify trustworthy recycling facilities or collection centers nearby.

EcoCycle AI must intelligently evaluate an electronic device and determine its best next destination.

The core routing rule is mandatory:

```text
IF device is Working or Repairable
    → Resell / Trade-In Engine

IF device is Non-Working / Dead / Scrap
    → Eco-Logistics Matchmaker
```

The system must never treat these two outcomes as the same.

The application must provide:

- AI-assisted device identification
- Device condition assessment
- Software/hardware diagnostic simulation
- Data sanitization workflow
- Verifiable destruction certificate
- Trade-in valuation
- Scrap valuation
- Resale/refurbishment recommendations
- Nearby recycling/collection recommendations
- Eco-credit calculation
- CO₂ savings estimation
- Complete user dashboard
- AI-generated recommendations
- Hackathon-ready demo experience

# 11. ROW LEVEL SECURITY (RLS) / DATA ISOLATION RULES

Enable RLS on all user-owned tables.

Users must only access their own:

- Devices
- Diagnostics
- Valuations
- Sanitization records
- Recommendations
- Eco-credit transactions
- Environmental impact
- Profile

Example:

```sql
alter table devices enable row level security;

create policy "Users can view own devices"
on devices
for select
using (auth.uid() = user_id);

create policy "Users can insert own devices"
on devices
for insert
with check (auth.uid() = user_id);

create policy "Users can update own devices"
on devices
for update
using (auth.uid() = user_id);

create policy "Users can delete own devices"
on devices
for delete
using (auth.uid() = user_id);
```

Apply equivalent policies to all user-owned tables.

Partners may be publicly readable but must not be publicly writable.

Never allow one user to access another user's device data.
